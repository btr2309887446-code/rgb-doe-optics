# 400–700 nm 可见光多尺度联合设计归档

本目录归档 2026-10-20 已完成的实验，包含多尺度分辨率目标及圆环控制组。**圆环在 400–700 nm 的 301 个采样点通过误差和 ROI 双门槛；多尺度目标尚未通过。** 380–780 nm 为单独的压力测试。

- [原始运行配置与代码来源哈希](provenance.json)

## 数据与图表

| 目录 / 文件 | 内容 |
|---|---|
| `target/` | 目标数组、物理采样元数据、采样检查与目标预览 |
| `multiscale/` | 多尺度目标的配置、报告、逐波长 CSV/JSON、分区相关性和自适应补点记录 |
| `annular_ring_control/` | 圆环控制组的配置、报告与逐波长 CSV/JSON |
| 各 case 的 `spectral_degree_2/design.npz` | 最终二阶参数、复系数、目标、孔径与物理坐标 |
| 各 case 的 `spectral_degree_3/design.npz` | 最终三阶参数、复系数、目标、孔径与物理坐标 |
| 各模型的 `spectral_validation.png` | 全范围的误差与 ROI 光谱曲线 |
| 各模型的 `validation_patterns.png` | 目标和代表性波长输出的共尺度对照 |
| [发布文件校验清单](archive_manifest.json) | 本目录发布文件及本次研究代码的大小和 SHA-256；另列本地大数组 |

`results.json` 的模型记录与 `summary.json` 对应；`metrics.csv` 同时含训练、验证和自适应阶段，比较时应保留 `model`、`split` 字段。多尺度最终三阶为 46 个训练点，二阶及圆环为 34 点，不能把最终二阶/三阶差值当成严格等预算的阶数消融。

原 `provenance.json` 保持不变。当前实验入口脚本与原记录的来源哈希不同，底层模型文件哈希一致；发布清单同时记录两者。公开最终设计已在 400/532/700 nm 逐一复算检查，重现保存的 L2 和 ROI 指标；这不等同于入口代码与原运行逐比特一致。

## 本地保留文件

每个模型的 `spectral_scan_images.npy` 是 401 个波长的完整强度数组，单份 100.25 MiB，未进入 Git；`checkpoints/` 是恢复用的中间参数，也保留本地。报告中的这些路径描述完整本地运行输出，不表示 GitHub 包含这些大文件。公开的最终设计可以直接传播重建这些数组，无需重新优化。

本目录只包含研究代码对应的数据与说明，PPT、Word 讲稿和本地演示构建文件不上传。自由复屏是数值模型，尚未实现为可加工的被动材料器件。
