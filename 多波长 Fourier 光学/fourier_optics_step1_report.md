# 多波长 Fourier 光学：Step 1 初步研究结果

## 摘要

本阶段验证“有限采样的复振幅屏经过理想薄透镜后，在后焦平面形成该屏函数的傅里叶变换”这一基础模型。使用显式物理坐标的 NumPy FFT，比较了圆孔径的 Airy 图样、有限矩形孔径上的线性相位光栅，以及一个复振幅屏与解析谱的对应关系；另以随机复屏检查直接离散求和和能量守恒。

**结果：**三个案例均符合对应的连续或离散模型。圆孔径归一化强度在首三圈内的 RMSE 为 `6.92×10⁻⁵`；光栅 FFT 与其精确离散 Dirichlet 求和的相对场误差为 `6.91×10⁻¹⁵`；随机复屏的 Parseval 功率误差为 `3.98×10⁻¹⁶`。这些结果验证了当前标量、傍轴、理想透镜模型中的坐标、归一化与 FFT 实现，尚未验证真实器件或多波长补偿。

## 1. 模型与推导

### 定义和假设

- `t(x,y)`：屏和有限孔径合并后的复振幅透过率。
- `U₀`：照明屏面的均匀平面波复振幅。
- `λ`：真空波长；`k=2π/λ`。
- `f`：理想薄透镜焦距。
- `(x,y)`：透镜输入面坐标；`(X,Y)`：后焦平面坐标。
- 傅里叶变换约定：

  `T(fx,fy) = ∬ t(x,y) exp[-i2π(fx x + fy y)] dx dy`。

采用标量傍轴 Fresnel 传播；屏紧邻理想薄透镜，透镜孔径已折入 `t(x,y)`。这不是对真实材料或器件相位的模型。

### 后焦平面的傅里叶关系

薄透镜的理想相位透过率为

`L(x,y;λ) = exp[-iπ(x²+y²)/(λf)]`。

将透镜后传播距离 `f` 的 Fresnel 积分写出：

`Uf(X,Y) = e^(ikf)/(iλf) ∬ U₀ t(x,y) exp[-iπ(x²+y²)/(λf)] exp[iπ((X-x)²+(Y-y)²)/(λf)] dxdy`。

展开传播核中的平方项后，输入面二次相位与透镜相位抵消，得到

`Uf(X,Y;λ) = U₀ e^(ikf)/(iλf) · exp[iπ(X²+Y²)/(λf)] · T(X/(λf), Y/(λf))`。

因此：

1. 忽略全局相位和不影响强度的输出二次相位后，后焦平面复场是屏函数的傅里叶变换。
2. 物理坐标满足 `fx=X/(λf)`、`fy=Y/(λf)`。
3. 若不同波长使用同一 `t(x,y)`，要保持同一物理坐标到频率的映射，理想模型要求 `λf(λ)` 不变。
4. 强度中还含有 `1/(λf)²` 因子；若 `λf` 固定，该因子也固定。实际系统还要考虑透射率和衍射效率。

薄透镜的后焦平面傅里叶性质也见 [MIT OpenCourseWare 的相关讲义](https://ocw.mit.edu/courses/2-71-optics-spring-2009/resources/mit2_71s09_lec18/)。

## 2. 离散模型和采样

对 `N×N` 屏、像素间距 `Δx=Δy`，输入窗口宽度为 `L=NΔx`。使用

`fx[p] = fftshift(fftfreq(N, Δx))`

以及 Riemann 积分归一化

`T[p,q] ≈ Δx² · fftshift(fft2(ifftshift(t)))`。

由此：

- 频率采样间隔：`Δf=1/L`。
- 输入面的 Nyquist 频率：`|fx|,|fy| ≤ 1/(2Δx)`。
- 后焦平面像素间距：`ΔX=λf/L`。
- 可表示的后焦平面坐标约为 `|X|≤λf/(2Δx)`。
- 对相位光栅，至少须满足 `1/Λ<1/(2Δx)`；工程 SLM 通常还需远高于每周期两个像素，来控制量化和填充因子误差。

零填充可以让绘图采样更密，但不会增加屏的空间带宽，也不会创造新的光学分辨率。

## 4. 仿真与解析对照

### A. 圆孔径 → Airy 图样

均匀照明圆孔径的连续归一化强度为

`I(u)/I(0) = [2 J₁(u)/u]²`，其中 `u=πD·sqrt(X²+Y²)/(λf)`。

连续模型的第一零点半径为 `1.21967 λf/D = 0.101385 mm`。离散焦平面上最接近该位置的采样点是 `0.103906 mm`，偏差 `2.49%`；该点归一化强度为 `3.68×10⁻⁴`。首三圈（`u≤12`）的归一化强度 RMSE 为 `6.92×10⁻⁵`，复场相对 L2 误差为 `1.76×10⁻³`。

第一零点没有恰好落在网格点上；这里报告的是最近采样点，偏差主要反映焦平面采样间距，而不是解析 Airy 公式与 FFT 的系统性冲突。圆孔径边缘按像素中心离散，也会带来小误差。

### B. 有限矩形孔径 + 线性相位光栅

屏函数为 `t(x,y)=P(x,y) exp(i2πx/Λ)`。矩形孔径连续解析谱是两个 sinc 函数的乘积，中心位于 `fx=1/Λ`。设置的光栅周期为 `158.269 µm`，每周期约 `31.65` 个输入像素；矩形孔径为 `4.005 mm × 4.005 mm`。

- 解析一级峰坐标：`X₁=λf/Λ=0.672273 mm`。
- FFT 采样峰坐标：`0.665000 mm`。
- 两者相差 `7.27 µm`，小于焦平面半个采样像素 `10.39 µm`；解析峰位落在两个 FFT 坐标之间。
- FFT 与屏幕离散样点的精确 Dirichlet 求和相对场误差：`6.91×10⁻¹⁵`。
- 与连续矩形孔径 sinc 模型比较，在主瓣局部区域的复场相对 L2 误差：`3.12×10⁻⁶`。

连续 sinc 与离散屏幕采样的差异在整个 Nyquist 频带内较大（相对 L2 误差约 `6.55×10⁻³`），因为连续矩形边缘包含任意高频，而离散屏幕只保留 Nyquist 带宽内的样点。主瓣误差很小，且离散 FFT 与精确离散求和一致。

### C. 复振幅屏 → 平移 Airy 谱

构造

`t=P_circle·(0.55 + 0.25e^(i2π(12x/L−4y/L)) + 0.15e^(i2π(−17x/L+13y/L)))`。

该复屏的连续解析谱是三个平移 Airy 场的相干叠加。以各载频附近 `u≤12` 的区域比较，数值复场相对 L2 误差为 `1.42×10⁻³`，最大复场误差相对于谱峰为 `4.77×10⁻⁴`。误差主要来自离散圆孔径边界。

另取固定随机种子的复振幅/相位屏，在 8 个 FFT 频率点上用显式离散求和独立核验 FFT，最大误差相对谱峰为 `1.05×10⁻¹⁴`。由 `Δf=1/(NΔx)` 做焦平面面积积分后，输入面与焦平面功率的 Parseval 相对误差为 `3.98×10⁻¹⁶`；带 Fresnel 透镜传播因子的焦平面功率误差同为 `3.98×10⁻¹⁶`。

## 6. 阶段结论

**VERIFIED**

- 理想薄透镜的 Fresnel 推导给出 `fx=X/(λf)`、`fy=Y/(λf)` 的后焦面频率映射。
- FFT 坐标、Riemann 归一化、圆孔径 Airy 形状、有限孔径光栅一级峰位置与屏函数傅里叶谱一致。
- 随机复屏通过独立离散求和和 Parseval 功率核验。

**NOT YET VERIFIED**

- PyOptica 中具体版本的实现或其结果与本 NumPy 基准的对照。
- 真实透镜、DOE、相位型 SLM 或超表面的色散、效率、偏振和相位量化。
- 多波长相同物理图案、任意强度目标的相位恢复，以及连续波段可实现性。

## 7. 当前模型的边界和下一步

当前结果只支持：在均匀相干平面波、标量傍轴 Fresnel 模型和理想透镜条件下，有限采样屏的数值傅里叶传播实现正确。它不证明真实器件能实现 `f(λ)∝1/λ`，也不证明任意强度图案或任意宽带目标可实现。衍射透镜的效率会随结构和设计条件变化，不能仅从焦距定律推出效率结论。[衍射透镜效率分析](https://pubmed.ncbi.nlm.nih.gov/11152007/)

建议下一阶段先做 **Step 2：任意复场的离散反变换与正向重构**，明确哪些误差来自有限支持、离散采样和物理孔径。之后再做相位型约束的 Gerchberg–Saxton；目标面随机相位场初始化后，迭代顺序应是“逆变换 → 屏面约束 → 正变换 → 目标面振幅约束”。
