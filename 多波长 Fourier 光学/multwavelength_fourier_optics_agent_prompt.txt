============================================================
二、此前已经得到的核心理论
============================================================

对于单色平面波：

    U_in(x,y) = U0

经过一个复振幅屏：

    t(x,y) = A(x,y) exp[i phi(x,y)]

之后：

    U0(x,y) = U0 t(x,y)

如果后面放置理想薄透镜，焦距为 f，则后焦平面近似为输入场的 Fourier transform：

    U_f(X,Y; lambda)
      ∝
    F[t]( X/(lambda f), Y/(lambda f) )

忽略不影响强度的整体相位因子。

核心坐标关系是：

    xi  = X/(lambda f)
    eta = Y/(lambda f)

所以普通固定焦距透镜满足：

    f(lambda) = f0

时，不同波长会导致 Fourier 图案在物理坐标上发生缩放：

    I_lambda(X,Y)
      ~
    I_lambda0(
        lambda0/lambda * X,
        lambda0/lambda * Y
    )

因此：

    同一个屏函数
    +
    普通固定焦距 Fourier lens
    =>
    不同波长通常不会得到完全相同的物理尺寸图案。

============================================================
三、目前最重要的理论猜想
============================================================

考虑一个色散 Fourier optical element，使有效焦距满足：

    f(lambda) = f0 lambda0/lambda

那么：

    lambda f(lambda)
      =
    lambda0 f0

因此：

    U_f(X,Y;lambda)
      ∝
    F[t](
        X/(lambda0 f0),
        Y/(lambda0 f0)
    )

于是 Fourier 平面坐标不再显式依赖 lambda。

因此在理想标量 Fourier optics 模型中：

    不同波长
    +
    同一个屏函数
    +
    f(lambda) ∝ 1/lambda
    =>
    相同的 Fourier 图案。

这是当前项目最重要的理论命题之一。

请你严格检查这个推导，而不是直接接受它。

特别需要检查：

1. 傅里叶透镜相位：
       phi_L =
       - pi/(lambda f(lambda)) (x^2+y^2)

2. 当
       f(lambda)=f0 lambda0/lambda
   时：
       lambda f(lambda)=lambda0 f0

3. 因此透镜相位可以变成波长无关形式。

4. 但真实 diffractive optical element 是否真的能实现这个有效焦距关系？

5. 需要区分：
   - ideal mathematical lens
   - refractive lens
   - diffractive lens
   - metasurface
   - phase-only DOE
   - achromatic / dispersion-engineered optical system

6. 真实系统是否还存在：
   - diffraction efficiency
   - material dispersion
   - finite aperture
   - finite NA
   - phase quantization
   - polarization dependence
   - higher diffraction orders
   - chromatic aberration
   - scalar approximation breakdown

============================================================
四、必须严格区分两个问题
============================================================

A. 任意复振幅目标：

给定：

    U_target(X,Y)

可以直接反 Fourier：

    t(x,y)
      =
    F^{-1}[U_target]

原则上得到复振幅屏函数。

B. 任意强度目标：

给定：

    I_target(X,Y)

只能知道：

    |U_target| = sqrt(I_target)

但未知相位：

    U_target =
    sqrt(I_target) exp[i phi(X,Y)]

因此需要求相位。

这变成：

    phase retrieval
    / computer-generated holography

可考虑：

    Gerchberg-Saxton
    Fienup
    IFTA
    Wirtinger flow
    double-phase encoding
    Lee hologram
    complex-amplitude encoding

请不要把“任意强度图案”与“任意复振幅图案”混为一谈。

============================================================
九、第五阶段：研究“基本图案”
============================================================

这是项目的数学核心之一。

注意：

“图案”如果指 intensity：

    I=|U|^2

一般不是线性空间。

真正适合做线性分解的是复振幅：

    U(X,Y)

因此应首先研究：

    H_image
      =
    space of complex optical fields

离散成：

    N x N

后：

    H_image ≅ C^(N^2)

于是存在有限维基。

最自然的基是 Fourier basis。

定义：

    t_mn(x,y)
      =
    exp[
       2 pi i
       (m x/Lx + n y/Ly)
    ]

其 Fourier transform 对应单个空间频率：

    F[t_mn]
      =
    delta(
       xi-xi_m,
       eta-eta_n
    )

离散系统中对应 Fourier-plane 的单个像素/spot。

因此：

    任意复场
      =
    sum_mn c_mn B_mn

其中：

    B_mn
      =
    Fourier basis pattern

而屏函数：

    t(x,y)
      =
    sum_mn c_mn t_mn(x,y)

这实际上就是 Fourier series。

请严格研究：

1. 完备性；
2. 正交性；
3. Parseval identity；
4. 离散 Fourier transform；
5. continuous Fourier basis；
6. finite aperture 下的修正；
7. finite pixel / finite SLM 下的修正；
8. spot 不再是理想 delta，而是 sinc-like pattern；
9. 空间带宽积；
10. optical degrees of freedom。

    sum_n c_n t_n(x,y)
